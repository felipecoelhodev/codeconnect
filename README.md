# Code Connect (Versão Divulgação de Conteúdo)

O **Code Connect (Versão Divulgação de Conteúdo)** é uma plataforma moderna de compartilhamento de conteúdo voltada para desenvolvedores. O projeto foca em uma experiência de usuário fluida, com sistema de autenticação, feed de postagens, interações sociais (curtidas e comentários) e total responsividade.
